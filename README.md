## 安装

```sh
dsh plugin --profile web add github:JRJRJPRO/dsh-tree
```

刷新浏览器就能用，**不用重启 dsh**。

装完它会出现在**插件市场的「已安装」**里，那儿的开关就是启用 / 停用，约 1 秒生效。
卸载：`dsh plugin --profile web remove dsh-tree`。

不依赖任何其它插件。

## 使用

| | |
|---|---|
| **单击节点** | 跳到那一轮 |
| **悬停** | 右侧出详情卡，上面只有两个动作：**＋** 和 **☆** |
| **在卡片上双击** | 展开：改名、形状、颜色、传图都在这一档 |
| **＋** | 从这之后接着问；在树根空节点上则是**在同一棵树里新开一条对话** |
| **☆** | 收藏 —— 这个点变成**黄色五角星**，滚到它那一轮时填实 |
| **改名** | 展开后单击文本框就能改。名字会直接写在树上 |
| **⇥ / ⇤** | 把这条支线拆成独立的一棵树 / 再接回去 |
| **⊕ / ⊖** | 树根空节点上：把本目录下别的对话**整棵**合并进来 / 拆回去 |
| **灰掉的按钮** | 现在做不了，鼠标停上去写着为什么 |

手机也能用 —— 没有悬停的设备上，「悬停」变成点一下。

### 收藏图标

收藏过的点，展开卡片后多出两排（就是上面右边那张图）：

- **12 个形状** —— 圆 / 圆角方 / 方 / 菱形 / 三角 / 倒三角 / 箭头 / 五边形 / 六边形 / 十字 / 四角星 / 沙漏。选择器上直接画出形状本身，按钮上看到的就是节点将来的样子
- **一个字** —— 填一个字，emoji 也行，节点就画成它
- **一张图** —— png / jpg / webp / svg 都行，尺寸不限，自动等比缩好。存在 `$DSH_HOME` 里，换浏览器也还在
- **颜色** —— 6 个预设加一个取色盘。描边色自动跟着算，在深浅底上都看得清

### 几条脾气

**改名改到一半时整张卡会锁住** —— 鼠标走开不关、划过别的点也不换点，否则手一滑刚敲的名字就没了。中文输入法打字不受影响。

**对话正在跑的时候，那条对话上的 ＋ 点不了**（只限 dsh-claude 这类把对话托管给外部引擎的会话）。新分支要继承上下文就得读它的记录，而读那个文件会打断它正在跑的那一轮。按钮灰着，鼠标停上去写明原因，跑完自动恢复 —— 不偷偷开一条"看着正常、其实不记得前情"的分支。

**撤回过的轮次不会再假装还在对话里**。答完才撤回的，留成一条岔出去的废弃支线；答到一半被中止再撤回的，那个节点直接不画。

**同一棵树** = 树根相同，或你主动在空节点上按 ＋ 开出来的对话。没登记过的对话各自成树，互不显示。

## 外观

颜色**跟着宿主主题走**，切浅色 / 深色树立刻跟着换，不用刷新。

**设置 → 插件 → 插件配置 → 对话树** 里一行一种（普通 / 当前路径 / 压缩 / 空节点 / 收藏），左边挑颜色右边挑形状。单独改过的那一项就钉死了，按「重置」交还回去。

同一张卡里还能调：

- **省略半径**（5–30 步，默认 12）—— 只画离当前这一轮若干步以内的节点。边界不硬切，最外两圈越画越小越淡，到边界正好消失；鼠标滑上去会把淡出撤掉，照样能点
- **节点大小**（50%–250%）—— 点、连线、列间距、命中区一起等比缩放

## 它还顺手修了两个原生 fork 的缺陷

- **会多抄一条还没跑的待办** —— 在节点 N 开岔路，新分支会先把 N+1 那个问题重跑一遍。所有 provider 都中招
- **外部引擎的记忆不跟随** —— 只影响 `dsh-claude` 这类桥接。不依赖它，装了才处理

两个都在 `agent/created` 上接管，用原生的分支按钮同样生效。

## 还没做

节点名字存在 localStorage · 左侧列表仍是平的 · 超长对话会溢出。
