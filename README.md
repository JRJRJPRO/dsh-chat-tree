# dsh-tree

把一个对话的所有分支画成一棵树，贴在 [DeepSeek Harness](https://github.com/deepseek-ai) 聊天区右缘。

点节点跳到那一轮，点 ＋ 从那儿接着问。

不依赖任何其它插件。运行时只多一个 `schemastery`（dsh 自己也用它，用来声明设置项）。

```
     ◌
     1
     2
 3'  3
 4'  4
```

## 装

```sh
dsh plugin --profile web add github:JRJRJPRO/dsh-tree
```

装完刷新浏览器就能用，**不用重启 dsh**（它会被热挂载）。卸载
`dsh plugin --profile web remove dsh-tree`。

装完之后它会出现在**插件市场的「已安装」里**，那儿的开关就是启用 / 停用：
开关写的是 `cordis.patch.yml` 的 `disabled` 行，约 1 秒生效，同样不用重启
（停用后连 `/plugins/dsh-tree/*` 那三个接口一起消失，不会留一半在跑）。
手动改也行，效果一样：

```yaml
- id: dsh-tree
  disabled: true
```

没有 `prepare` 脚本，`client.js` 是**提交进仓库的成品**，所以 git 安装不会触发
pnpm 的构建闸（不用去 `pnpm-workspace.yaml` 里加 `allowBuilds`）。

**本地开发**：`npm install`（要一个 `schemastery`），然后把工作目录直接链进 profile ——

```sh
dsh plugin --profile web add link:D:/绝对路径/dsh-tree
```

这样 `node_modules/dsh-tree` 是个指向你工作目录的符号链接：市场照样把它列进「已安装」，
而你改完 `npm run build` 刷新页面就见效，不用重装。
⚠️ 别再往 `cordis.patch.yml` 里写 `file:///…` 的 `insert` —— 和上面的装法同时用
会让同一个 id 插两次，cordis 直接拒绝启动。

代码分成 host 半（`src/host/`，入口 `index.js`）和浏览器半（`src/client/`）。
浏览器半必须是一个文件（dsh 的规矩），所以 `client.js` 是 `npm run build` 拼出来的
**生成物，别手改**。改 host 半要重启 dsh；改浏览器半 `npm run build` 再刷新页面，
或者开着 `npm run watch` 自动重拼。

改哪个文件、加东西要动哪几处，见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 用

| | |
|---|---|
| 单击节点 | 跳到那一轮 |
| 悬停 | 右侧出详情卡 |
| 双击名字 | 改名 |
| ＋ | 从这之后接着问；在树根空节点上则是**在同一棵树里新开一条对话** |
| ⇥ | 把这条支线拆成独立的一棵树（头顶有岔路的节点才有） |
| ⇤ | 把拆出去的支线接回原来那棵树（出现在剪缝上） |
| ⊕ | 树根空节点上：把本目录下别的对话**整棵**合并进来，再点一次 ⊖ 拆回去 |
| 灰掉的按钮 | 现在做不了，鼠标停上去写着为什么 |

有一头还在跑的时候不让合并 —— 那条会留在单子里灰掉，右边写着「这条对话还在运行，跑完再合」。

**对话正在跑的时候，那条对话上的 ＋ 也点不了**（只限 dsh-claude 这类把对话托管给外部引擎的
会话）：新分支要继承上下文就得读它的记录，而读那个文件会打断它正在跑的那一轮。按钮灰着不动，
鼠标停上去写明原因，跑完自动恢复 —— **不偷偷开一条"看着正常、其实不记得前情"的分支**。

万一还是出现了没继承到上下文的分支（比如用原生的分支按钮开的），那条分支的头一个节点上会挂
一块「无上下文」的牌子。

边框蓝 = 这个节点在你当前的对话里；填充蓝 = 你正看着这一轮。橙色倒三角 = 这一轮做过压缩。

**撤回过的轮次**（dsh-claude 的 rewind）不会再假装还在对话里：答完之后才撤回的，
留成一条岔出去的废弃支线，后面新发的那轮接回撤回**之前**那个节点；答到一半被中止
再撤回的，那个节点直接不画。撤回的节点详情卡上挂着「撤回」牌子，也不给 ＋ 按钮
（claude 那边的锚点已经跟着删了，从那儿开分支只会是条失忆分支）。

撤回记录存在 dsh-claude 自己的文件里，而**读那个文件会打断正在跑的那一轮**
（Windows 上开着读句柄，对面的原子写就会失败）。所以这条会话只要有轮次在跑，
插件就一个字节都不读，画的是上一次读到的状态；导轨上沿会出现一个 ⏳，
鼠标停上去有说明，那一轮跑完自动更正。细节见 [DESIGN.md](DESIGN.md) §3。

同一棵树 = 树根相同，或你主动在空节点上按 ＋ 开出来的对话。没登记过的对话各自成树，互不显示。
分组关系存在 `$DSH_HOME/plugins/dsh-tree/shape.json`。

## 省略

只画离你正在看的那一轮若干步以内的节点。距离是树上的无向步数：父节点 1 步，父节点的另一个孩子 2 步。

边界不硬切：最外两圈越画越小、越画越淡，到边界正好消失（鱼眼），没有 `⋯` 之类的记号。淡出圈吃的是半径自己的最外层 —— 设置里写「12 步」就是最远画到 12 步，不会偷偷多画。鼠标滑上去会把淡出撤掉，照样能点。

默认 12 步。**设置 → 插件 → 插件配置 → 对话树** 里可调，5 到 30，再往上一档是不省略。

同一张卡里还能调**节点大小**（50%–250%）：点、连线、列间距、命中区一起等比例缩放。

## 配色

普通节点 / 当前路径 / 压缩节点 / 空节点，一个角色一行，左边挑颜色右边挑形状。

形状有圆形 / 圆角方 / 方形 / 菱形 / 倒三角，选择器上直接画出形状本身，还跟着这一行选的
颜色走。四个角色的形状各自独立。空节点的虚线边是「还没说话」的记号，不跟着配置走。

预设后面还有两格自定义：

- **传图片** —— png / jpg / webp / svg 都行，**尺寸不限**。浏览器会先把它等比缩进
  96×96（空出来的地方透明补齐，不会拉变形）再存到 `$DSH_HOME/plugins/dsh-tree/icons/`，
  换浏览器也还在。只留最近 32 张。
- **填字符** —— 填一个字，emoji 也行，节点就画成它。

> 传上去的图会先过一遍 canvas 转成 PNG。SVG 里可以写脚本，原样存下来再当图片引不安全。

改了主色，路径垫色、外发光、连线都跟着变。

## 它还顺手修了两个原生 fork 的缺陷

- **会多抄一条还没跑的待办** —— 在节点 N 开岔路，新分支会先把 N+1 那个问题重跑一遍。所有 provider 都中招。
- **外部引擎的记忆不跟随** —— 只影响 `dsh-claude` 这类把对话托管给外部引擎的桥接。不依赖它，装了才处理。

两个都在 `agent/created` 上接管，原生分支按钮同样生效。

## 测

```bash
npm test                   # 先构建，再十套一起跑

node test.mjs              # 真实会话日志跑整条渲染管线，--print 打印 ASCII 树
node test-highlight.mjs    # 高亮、hover intent、连线遮挡
node test-elide.mjs        # 省略的距离、行号压实、缩放
node test-icon.mjs         # 自定义节点图片：只收 PNG、内容哈希、清理不误伤
node test-rewind.mjs       # 撤回：哪些轮该消失、哪些该成废弃支线
node test-merge.mjs        # 合并 / 接回去
node test-shape.mjs        # 拿真实会话跑合并 / 分离的端到端
node test-branch.mjs       # 把真实分支倒带到"刚出生"，重放接管逻辑
node test-http.mjs         # 路由外壳：方法分发、出错码、图片走原样字节
node test-lifecycle.mjs    # 启用 / 停用 / 再启用：两半都不许留东西
```

单独跑某一个之前记得 `npm run build` —— 测的是生成物 `client.js`。

`test-branch.mjs` 要读真实会话日志，不在默认位置时设 `DSH_HOME_REAL` 指过去，否则它自己跳过。
